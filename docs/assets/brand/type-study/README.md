# Type study

Runwell uses the terminal pairing (runwell-icon.svg, runwell-lockup-*.svg in the folder above). The other two are kept for reference.

Marks and wordmarks built from open-source typefaces (SIL Open Font License), converted to paths so the files need no font:

- editorial: Instrument Serif (italic r, and "Runwell")
- terminal: Geist Mono (r with a block cursor, and "runwell" ending in the cursor); cursor colour #c6f432
- bold: Bricolage Grotesque ("rw", and "runwell")

`typefaces.png` is the wider first round (Geist, Bricolage, Syne, Space Grotesk, Instrument Serif, DM Serif Display, Geist Mono).
